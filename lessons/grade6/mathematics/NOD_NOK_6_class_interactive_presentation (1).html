НОД и НОК

Сегодня разберём две похожие аббревиатуры так, чтобы они больше не путались.

НОД

делим на группы

Ищем самое большое число, которое делит оба числа без остатка.

НОК

ищем общую встречу

Ищем самое маленькое число, которое кратно обоим числам.

Переключение: кнопки снизу или клавиши ← →.

Шаг 0. Вспомним два слова

Делитель

Число, на которое можно разделить без остатка.

$12:3=4$

Значит, $3$ — делитель числа $12$.

Кратное

Число, которое получается, если данное число умножить на натуральное число.

$3\cdot4=12$

Значит, $12$ — кратное числа $3$.

Подсказка: делители обычно меньше числа, а кратные могут расти дальше и дальше.

Проверим основу

Что верно для числа $18$?

НОД: что означает?

НОД = наибольший общий делитель.
Это самое большое натуральное число, на которое оба числа делятся без остатка.

Найдём НОД$(12,18)$.

Делители 12

123612

Делители 18

1236918

Общие: $1,2,3,6$. Самый большой — $6$.

НОД$(12,18)=6$

Как понять, что задача про НОД?

Разделить поровну

Нужно сделать одинаковые наборы без остатка.

Самый большой размер

Нужна максимально большая одинаковая группа, плитка, шаг, кусок.

Общий делитель

Одно число должно делить сразу несколько чисел.

Есть $18$ красных и $24$ синих карандаша. Хотят сделать максимально возможное число одинаковых наборов без остатка. Что нужно искать?

НОД через простые множители

Для больших чисел перечислять все делители долго. Тогда раскладываем числа на простые множители.

$36=2\cdot2\cdot3\cdot3$
$48=2\cdot2\cdot2\cdot2\cdot3$
Найди одинаковые простые множители.
У обоих чисел есть две двойки и одна тройка.
Возьми только общие множители.
$2,\;2,\;3$.
Перемножь.
$2\cdot2\cdot3=12$.

НОД$(36,48)=12$

Практика: НОД

Найди НОД$(24,36)$.

Можно начать так: $24=2\cdot2\cdot2\cdot3$,   $36=2\cdot2\cdot3\cdot3$.

НОК: что означает?

НОК = наименьшее общее кратное.
Это самое маленькое положительное число, которое делится и на первое, и на второе число.

Найдём НОК$(4,6)$.

Кратные 4

4812162024

Кратные 6

6121824

Первая общая встреча — $12$.

НОК$(4,6)=12$

Как понять, что задача про НОК?

События повторяются

Автобусы, сигналы, звонки, вращения.

Когда снова вместе?

Нужно найти первую общую встречу во времени.

Общее кратное

Искомое число должно делиться на каждое из данных.

Один фонарь мигает каждые $6$ с, второй — каждые $8$ с. Через сколько секунд они впервые снова мигнут вместе?

НОК через простые множители

$12=2\cdot2\cdot3$
$18=2\cdot3\cdot3$
Начни с множителей первого числа.
$12=2\cdot2\cdot3$.
Добавь недостающие множители второго числа.
Для $18$ не хватает ещё одной тройки.
Перемножь всё.
$2\cdot2\cdot3\cdot3=36$.

НОК$(12,18)=36$

Частая ошибка: для НОД берём только те простые множители, которые есть у обоих чисел. Для НОК берём все множители первого числа и добавляем недостающие из второго.

Главная шпаргалка: не перепутай

НОД

Д = Делить

Самый большой делитель.

В разложении: берём только общие множители.

↔

НОК

К = Кратное

Самое маленькое кратное.

В разложении: берём все нужные множители, без повторного учёта одинаковых.
